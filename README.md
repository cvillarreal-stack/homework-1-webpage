# Project Milestone 1: Site Plan & HTML Skeleton

This repository contains the foundational HTML structure and site plan for my personal portfolio.

## Project Structure
- `index.html`: Home page
- `projects.html`: Featured projects and work
- `about.html`: About me and contact details
- `wireframe.md`: Wireframe layouts and site plan design notes

## Site Plan & Design Notes
- **Primary Color:** `#1A1A2E` (Dark Slate / Navy)
- **Secondary Color:** `#0F3460` (Deep Blue)
- **Accent Color:** `#E94560` (Coral / Crimson)
- **Background Color:** `#F8F9FA` (Off-white / Soft Grey)
- **Typography / Fonts:** 
  - Primary Body: *Inter* or *System Sans-Serif*
  - Headings: *Roboto* or *Helvetica*
